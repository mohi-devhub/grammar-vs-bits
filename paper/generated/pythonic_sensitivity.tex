\paragraph{Separate Pythonic-format sensitivity.} We collected 4,800 responses on 120 cases: the original parallel and a separately sampled parallel-multiple subset. Both Llama models used both precisions, free and whole-strict decoding, and the same operational labels. The prompt uses Meta's call-list syntax, omits the HF tools instruction and uses \texttt{[]} for abstention. Llama-3.2-1B Q4 whole-strict parallel accuracy is 62.3 [50.0, 74.3]\%, versus 1.0\% under the original JSON contract. Its Pythonic parallel incremental recovery is 1.7 [-10.3, 13.7] points; the paired change in recovery versus JSON is 2.3 [-10.0, 15.0] points. Llama-3.2-3B Q4 whole-strict parallel accuracy is 88.3 [80.0, 95.7]\%, versus 0.0\% under the original JSON contract. Its Pythonic parallel incremental recovery is -3.3 [-8.7, 0.7] points; the paired change in recovery versus JSON is -3.3 [-8.7, 0.7] points. The paired Q4 contract gains are positive. Sensitivity parallel incremental recovery and its protocol change remain inconclusive. Only the original parallel items are matched across the changed prompt, parser and grammar. Parallel-multiple scores are separate. Sessions differ in time and host; this is not a randomized crossover. A platform interruption left 1,610 saved Llama-3B outputs. Another A10 collected the remaining 790 responses, retaining all saved failures. The primary matrix is unchanged.
